**Time.** Summer 2025  
**Affiliation.** ByteDance Volcengine Ark Group – Arkitect SDK  
**Role.** Agent systems intern (cookbook owner)  

**Tagline.** Dual-track onboarding (human-friendly notebook + agent-ready script) that makes Arkitect approachable and automatable.

**Summary.** Took the monolithic Arkitect “cookbook” and rebuilt it into a modular teaching + automation asset that now lives in the official open-source repo.

**Highlights.**
- Authored a narrative Jupyter path for humans plus a minimal Python script path for autonomous agents, so teams can mirror walkthroughs with executable templates.
- Split implicit hook spaghetti into composable modules covering context initialization, tool registration, orchestration, logging, and verification, greatly improving reuse and reproducibility.
- Added inline diagnostics (structured logging, dry-run validators) so newcomers can see what each hook contributes before deploying to production.
- PR merged into `volcengine/ai-app-lab`, and several internal teams under the ML Platform now use it as the default scaffold for new Arkitect projects.

**Keywords.** LLM tool use, SDK design, documentation, open source, reproducibility.
